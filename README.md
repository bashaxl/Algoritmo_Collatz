# 🔢 || Algoritmo de Collatz // Collatz algorithm:
> __Reto__: Crear un programa basado en el algoritmo de Collatz, el programa deberá cumplir con la logica necesaria para considerarse el algoritmo. También deberá imprimir en pantalla los resultados de las cuentas hechas, y guardar dichos datos en una memoria donde se consulte si los calculos se hicieron anteriormente.
> 
> __Challenge__: To create a program based on the Collatz algorithm, the program must comply with the necessary logic to be considered an algorithm. It must also print the results of the calculations performed on the screen and save said data in a memory where it can be consulted if the calculations were performed previously.

# 📚 || Requisitos y logica // Requirements and logic:
> El programa deberá tomar un numero entero y positivo, al tomarlo tendrá que hacer las siguientes cosas:
> 
>  Si el numero es par, lo divide entre 2 <br>
>  Si el numero es impar, se multiplica por 3 y se le suma 1 <br>
>  Se repetirá el proceso hasta que el numero sea 1 <br>
>  Conforme calcula el numero, deberá guardarlo en una variable que imprimira luego <br>
>  Finalmente, el programa deberá comprobar si el calculo se hizo anteriormente y si es así, devolver los calculos hechos para optimizar el programa. <br>
>
> The program must take a positive integer. When taking it, it must do the following:
> 
> If the number is even, divide it by 2 <br>
> If the number is odd, multiply it by 3 and add 1 <br>
> The process will be repeated until the number is 1 <br>
> As it calculates the number, it must save it in a variable that it will print later <br>
> Finally, the program must check if the calculation was done previously and, if so, return the calculations made to optimize the program. <br>
>
